# Sentiment Analysis Naive Bayes

Web-based sentiment analysis system for analyzing public opinion on post-protest asset takeover issues using Natural Language Processing (NLP) and the Naive Bayes algorithm.

---

## Features

- User authentication (Login & Register)
- Indonesian text preprocessing
- Sentiment classification (Positive, Neutral, Negative)
- Naive Bayes machine learning model
- Dataset management
- Model training and evaluation
- Confusion matrix visualization
- Accuracy, Precision, Recall, and F1-Score evaluation
- Web-based dashboard interface

---

## Technologies Used

- Python
- Flask
- MySQL
- Scikit-learn
- Pandas
- Sastrawi
- HTML/CSS/JavaScript

---

## NLP Preprocessing

- Case Folding
- Tokenization
- Stopword Removal
- Stemming
- Text Normalization

---

## Machine Learning

Algorithm used:
- Multinomial Naive Bayes

Evaluation metrics:
- Accuracy
- Precision
- Recall
- F1-Score

---

## Dataset

The dataset was collected from public opinion on platform X (Twitter) related to post-protest asset takeover issues.
